# 米粉と鉄板 モバイルオーダー

米粉と鉄板を使ったテイクアウト店向けの、**QR コードからスマホで注文 → 番号呼び出し → 店頭会計** のシステムです。
Java（Spring Boot）で作られています。

```
  お客さん                    厨房                     店長
  ─────────                 ─────────                ─────────
  QR を読む                  注文が届く                メニューを登録する
     ↓  スマホ                  ↓  タブレット             ↓  PC
  メニューを見る             焼き始める（調理中）       売上を見る
     ↓                         ↓                        ↓
  カートに入れる             焼き上がり（お渡し可）     QR を印刷する
     ↓                         ↓
  注文する  ──────────→   番号を呼び出す
     ↓                         ↓
  番号が出る                 受渡・会計
```

## 動かしてみる

### 必要なもの

| もの | バージョン | 確認コマンド |
|---|---|---|
| JDK | **21 以上** | `java -version` |
| Maven | 3.9 以上（無くても後述のスクリプトが用意します） | `mvn -v` |

JDK が入っていない場合は [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21) をインストールしてください（Windows なら `.msi` を選ぶのが簡単です）。

### いちばん簡単な起動方法

PowerShell でプロジェクトのフォルダを開いて：

```powershell
.\tools\run.ps1
```

Maven が入っていなければ自動でダウンロードして使います（`.tools\` 配下・`.gitignore` 済み）。

起動したらブラウザで <http://localhost:8080> を開いてください。

### Maven が入っている場合

```powershell
mvn spring-boot:run
```

### IntelliJ IDEA / VS Code で開く場合

- **IntelliJ IDEA**: `File → Open` でこのフォルダを選ぶ → 依存関係が自動で取得される → `KomekoOrderApplication` の左の ▶ を押す
- **VS Code**: 拡張機能「Extension Pack for Java」を入れてフォルダを開く → `KomekoOrderApplication.java` の `Run` を押す

### 初期アカウント

初回起動時にメニューと初期アカウントが作られます。
**パスワードはランダムに自動生成され、起動ログに 1 回だけ表示されます。**

```
============================================================
 初期アカウントを作成しました。（パスワードは自動生成しました）
   管理者   : admin / xxxxxxxxxxxxxx
   スタッフ : kitchen / xxxxxxxxxxxxxx
============================================================
```

| 用途 | ユーザー名 | 権限 |
|---|---|---|
| 管理者 | `admin` | メニュー編集・売上・スタッフ管理まで |
| 厨房スタッフ | `kitchen` | 注文の進行管理のみ |

> **この表示を見逃したら**、`data\` フォルダを消して起動し直すと作り直されます。
> パスワードを自分で決めたい場合は、起動前に環境変数を設定してください。
>
> ```powershell
> $env:INITIAL_ADMIN_PASSWORD = "好きなパスワード"
> .\tools\run.ps1
> ```
>
> 設定ファイルに直接書かないのは、**Git にコミットすると履歴に残り続ける**ためです。

### データを最初からやり直したい

`data\` フォルダを丸ごと削除して起動し直してください（H2 データベースと画像がここに入っています）。

## できること

**お客さん側**

- QR を読むだけで注文できる（アプリのインストール・会員登録は不要）
- カテゴリタブ付きのメニュー、写真、説明、価格（税込表示）
- **アレルゲン表示**と「小麦不使用」バッジ（米粉の店の一番の売り）
- サイズ・トッピングなどのオプション選択、金額がその場で変わる
- 注文番号と待ち組数・待ち時間の目安がリアルタイムに更新される
- 焼き始める前なら自分でキャンセルできる

**厨房側**

- 受付 → 調理中 → お渡し可 → 受渡済 の 3 レーンのボード
- 新しい注文が入ると **音が鳴って自動で画面が更新**される（SSE）
- 15 分以上経過した注文は赤枠で警告
- 品切れをワンタップで切り替え、即座にお客さんの画面へ反映

**店長側**

- メニュー・カテゴリ・オプションの登録／編集（画像アップロード対応）
- 売上サマリ、商品別ランキング、直近 7 日の推移
- QR コードの生成・印刷用ポップ
- 混雑時に**注文受付を一時停止**できる非常ブレーキ
- 営業時間・ラストオーダー・税率・「鉄板で同時に焼ける数」などの設定

## 技術構成

| 分類 | 使っているもの | 選んだ理由 |
|---|---|---|
| 言語 | Java 21 | LTS で長く使える |
| フレームワーク | Spring Boot 3.3 | Web サーバ・DI・セキュリティが一式そろう |
| 画面 | Thymeleaf（サーバサイド描画） | JavaScript フレームワーク無しで完結し、学習コストが低い |
| DB | H2（ファイル） / PostgreSQL | H2 はインストール不要。本番は PostgreSQL に切り替え可能 |
| 認証 | Spring Security（フォームログイン・BCrypt） | 自作しない。認証は自作が最も危険な領域 |
| リアルタイム | SSE（Server-Sent Events） | サーバ→ブラウザの一方向で足りるため WebSocket より単純 |
| QR 生成 | ZXing core | 依存を増やさないよう PNG 化は Java 標準の ImageIO で自作 |
| CSS | 素の CSS（フレームワーク無し） | 和モダンな見た目を細部までコントロールするため |
| ビルド | Maven | 情報が多く、初学者が調べやすい |

## 店内で実際に使うときの設定

### 1. QR の飛び先を LAN の IP に変える

初期状態では `http://localhost:8080` を指しているため、**お客さんのスマホからは開けません**。
アプリを動かす PC の IP アドレスを調べて設定します。

```powershell
ipconfig    # 「IPv4 アドレス」を確認（例: 192.168.0.10）
```

`src/main/resources/application.yml` を書き換えます。

```yaml
app:
  base-url: http://192.168.0.10:8080
```

書き換えたら再起動し、`/admin/qr` で QR を印刷してください。

### 2. Windows のファイアウォールを開ける

同じ Wi-Fi のスマホから届くように、8080 番ポートの受信を許可します（管理者権限の PowerShell）。

```powershell
New-NetFirewallRule -DisplayName "Komeko Order 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

### 3. 店舗設定を自分の店に合わせる

`/admin/settings` で以下を設定します。

- 店舗名・キャッチコピー
- 営業時間・ラストオーダー時刻
- **鉄板で同時に焼ける数** … 待ち時間の目安の計算に使います
- 営業日の切り替え時刻 … 深夜営業をしないなら既定の 5 時のままで大丈夫です

### 4. サイネージ

店頭のディスプレイをつないだ PC で `/display` を開き、ブラウザを全画面（F11）にしてください。
ログイン不要で開けます。

> **注意**：`/display` は認証なしで見られます。番号しか表示しませんが、
> 店外から見える位置に置く場合はその点をご承知おきください。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 起動時に `UnsupportedClassVersionError` | JDK が 21 未満。`java -version` を確認 |
| ポート 8080 が使用中 | `application.yml` の `server.port` を 8081 などに変更 |
| POST したら 403 が返る | フォームに `th:action="@{...}"` を使っていない（CSRF トークンが入らない） |
| 画面で `LazyInitializationException` | `open-in-view: false` のため、Service の中で必要な関連を読み終える必要がある |
| スマホから QR を読んでも開けない | `app.base-url` が `localhost` のまま。上の「店内で使うときの設定」を参照 |
| 厨房画面が自動更新されない | ブラウザが SSE を切っている可能性。30 秒ごとの再読込にフォールバックします |
| メニューを変えたのに反映されない | 初回だけサンプル投入され、以後はスキップされます。`data\` を消すとリセット |

## ライセンス / 注意

- 学習および自店舗での利用を想定した個人プロジェクトです。
- **アレルゲン表示は本システムが保証するものではありません。** 実際にお客さまへ案内する内容は、必ず仕入元の原材料表示を確認したうえで店舗の責任で登録・運用してください。
- 決済機能は含みません（会計は店頭）。
