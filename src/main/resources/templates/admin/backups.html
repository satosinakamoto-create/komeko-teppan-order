定時は PC が落ちていると走りませんが、その場合も 翌日アプリを起動した瞬間に「追いつき」が自動で取られます。 設定（時刻・世代数・2次コピー先）は application.yml の app.backup で変更できます。 2次コピー先に USB ドライブか OneDrive のフォルダを指定しておくと、 この PC のディスクが壊れたときの保険になります。

復元のしかた（もしものとき）

復元は誤操作の被害が大きいため、画面からのボタン操作ではできないようにしています。 手順の概要は次の通りです（詳細は docs\バックアップと復元.md）。

  1. アプリを停止する
  2. いまの data\komeko.mv.db を別名にして退避する（すぐ消さない）
  3. 戻したい世代の database.zip を展開し、出てきた .mv.db ファイルを data\komeko.mv.db として置く
  4. uploads.zip を data\uploads\ に展開する
  5. アプリを起動し、メニュー・伝票が戻っていることを確認する
