## 2. 決定事項

### やると決めたこと（実装済み）

- 卓番QR・1卓1伝票・店頭会計（オンライン決済なし）
- 伝票の金額計算は `TableSession.recalculate` の**1箇所に集約**（小計＋チャージ¥450×人数＋23時以降10%）
- 設定は**来店時点の値を伝票にコピー**（営業中に設定変更しても既存伝票は不変）
- 価格は税込 int・税率10%（酒類ありのため軽減税率対象外）
- アレルゲンは**意図的に未登録**（店舗が原材料確認して登録。未登録は「店舗へお尋ねください」表示）
- 「時価」商品は売り切れ状態で登録（0円注文事故の防止）
- バックアップの復元は**画面から不可**（誤操作の被害が最大級のため手順書方式）
- 残数は null=無制限のオプトイン方式。日次自動リセットなし（仕込み数は日々違う）

### やらないと決めたこと（理由つき・CLAUDE.md にも記録）

| 項目 | 理由 | 再検討条件 |
|---|---|---|
| ログイン試行制限 | 店内LANでは総当たりの現実性が低く、営業ピーク中のロックアウトの実害が大きい | ネット公開時は必須 |
| DB/バックアップ暗号化 | 個人情報ゼロ設計で被害上限が低い。鍵紛失で自分のバックアップが開けなくなるリスクの方が大 | 個人情報を扱い始めたら |
| HTTPS | 自己署名証明書は客のスマホに警告→注文UX が死ぬ。証明書の90日更新失敗＝全卓注文不能の新事故 | ネット公開・決済導入時は必須（`order.komekototeppan.com`＋DNS認証の道あり） |
| サイネージ・番号呼び出し | イートインでは不要（8/16 に削除。コミット `376875e` に残存） | — |

## 3. 議論で出た考え方（Q&A のエッセンス）

- **「シンプルなシステムだよね」** → 業務フローは確かに単純。難しさは「縁」に集中する：同時実行（採番・在庫）／金額（キャンセル再計算・スナップショット）／時刻（日跨ぎ営業・深夜料金）。実際に修正したバグは全部そこだった
- **「銀行と同じ仕組み使えば？」** → 正解。RDB のトランザクション（ACID）自体が銀行由来。腕の見せ所は①直列化の**粒度**（全体でなくカウンタ1行だけロック）②「時刻に反応する」でなく「**タイムスタンプから導出する**」（リセット処理は存在しなければ失敗もしない）
- **「停電したらデータ消える？」** → 確定済みはディスク（DB）なので消えない。RAM にあるのはカート等の未確定分だけ。同じ卓の QR を読み直せば伝票に戻れる。怖いのは停電よりディスク故障→バックアップで対処
- **「時間でバックアップしてるなら閉じる順序関係なくね？」** → 定時はアプリ内スケジューラなので PC が寝てたら走らない＆逃した回の再実行なし → **起動時追いつき**を実装して解決
- **「有線だけの時実行にしたい」** → アプリに有線/無線は見えない。**DHCP固定予約で IP＝端末**にし、IP許可リストで実現（パスワードと独立した二重ロック。IP偽装は可能なので「錠を増やす」対策）
- **「テストが通る＝安全」ではない** → テストが使っていない設定（dev の DB URL）は守られない、を初回起動で実体験

## 4. 発見・修正したバグ（時系列）

テスト・実起動が捕まえたもの。ハッピーパス上のバグはゼロで、全部「縁」だった。

1. 採番カウンタが初回同時注文で巻き戻る可能性 → `Persistable` で必ず INSERT
2. 営業時間の日跨ぎ（17:30〜26:00）で受付判定が常に false → 日跨ぎ対応
3. アレルゲン未登録の全品に「小麦不使用」バッジ → 未確認扱いに変更
4. `@EntityGraph` に allergens 書き忘れ → メニュー画面 500（EAGER 宣言でも LAZY に上書きされる仕様）
5. モデル属性名 `session` が Thymeleaf 予約変数と衝突 → `bill` に変更
6. GET `/login` ハンドラ欠落 → リダイレクトループ
7. ホール一覧と伝票詳細の金額食い違い（23時前後）／会計ダイアログが深夜料金チェックに追従しない
8. `run.ps1` の BOM 無し UTF-8 構文エラー／`2>&1` の PowerShell 5.1 問題
9. バックアップ命名：同秒連続実行で**作った直後のバックアップが間引きで消える** → 「既存より必ず新しい名前」に修正
10. H2 URL の `AUTO_SERVER`+`DB_CLOSE_ON_EXIT` 併用不可 → 初回実起動で発覚
11. テスト自体のバグ 2 件：卓名20文字制限超過／**「自分は通るが他人を落とす」非トランザクションテスト**（実行順依存汚染）
